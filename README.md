# Thugger Usernames List

Telegram-бот на Node.js без внешних npm-зависимостей. Публичный каталог юзернеймов, аккаунты и их счётчики, поиск, статусы, цены и заметки. Добавление, изменение и удаление — только для владельца `1900349507` (проверяется и в обработчиках, и в хранилище).

Привязка юзернейма к аккаунту — запись владельца каталога, не автоматическая проверка владения Telegram/Fragment. Бот не подключается к личным Telegram-сессиям и не собирает чужие юзернеймы. Названия аккаунтов, цены и заметки публичны: не указывай номера телефонов и секреты.

## Первый запуск на Windows

1. Установи Node.js 22+ и Git for Windows.
2. Открой терминал в папке, где хочешь хранить бота:
   ```sh
   git clone https://github.com/trgrnw/thugger-usernames-list.git
   ```
   Для приватного репозитория Git запросит авторизацию GitHub.
3. Открой папку `thugger-usernames-list` и запусти `start.bat`.
4. При первом запуске откроется `.env`. Вставь токен после `BOT_TOKEN=`, сохрани и закрой Блокнот. Не добавляй кавычки/пробелы к токену.
5. Не закрывай окно запуска. Открой своего бота в Telegram → `/start` → «Админ-раздел» → добавь аккаунт, затем юзернеймы.

`start.bat` проверяет GitHub каждые 30 секунд и получает изменения из `main`, затем автоматически перезапускает бота. Файлы скачивать заново не нужно. GitHub хранит код и запускает проверки; сам бот работает на твоём компьютере. При выключении компьютера бот недоступен. Запускай только один экземпляр бота с одним токеном.

Локальные изменения в отслеживаемых файлах приостанавливают автообновление, чтобы их не затереть. Скрипт автообновления загружается при запуске: после изменения самого `scripts/auto.js` перезапусти окно. Обновления на GitHub проходят тесты; локальный runner обновляет опубликованный `main`.

## Команды и данные

- `/start` — главное меню.
- `/admin` — админ-раздел владельца.
- `/cancel` — отменить текущий ввод.
- `npm start` — обычный запуск с `.env`.
- `npm run dev` — автоматический перезапуск при локальных изменениях исходников.
- `npm test` — тесты прав, сохранения и сценария добавления.

Каталог сохраняется в `data/catalog.json` атомарной заменой файла. Он и `.env` исключены из Git. Сделай резервную копию `data` перед переносом на сервер. Пустой каталог создаётся при первом сохранении. Незавершённый ввод сбрасывается при перезапуске, сохранённые записи остаются. Хранилище рассчитано на один процесс.

## Постоянный запуск

На VPS скопируй `.env` и `data` и запускай бот через менеджер служб (например, systemd). Автоматический runner `node scripts/auto.js` также работает на Linux при наличии Git и доступа к репозиторию. Не используй долгоживущий GitHub Actions job как хостинг бота.

Токен хранится только в `.env` или секретах хостинга. При замене через BotFather обнови `.env` и перезапусти окно запуска. Если Telegram возвращает 409, останови второй экземпляр; при 401 проверь токен. Включённый webhook нужно отключить перед polling-запуском.
